Servux-Paper
==============
Servux is a server-side mod that provides extra support/features for some client-side mods when playing on a server. This fork is expressly modified to send MiniHUD Servux channels from Paper (Bukkit) servers.

**Servux itself is never needed on the clients or in single player**,
it's only needed/useful on the dedicated server side in multiplayer.

Compiling
=========
* Clone the repository
* Open a command prompt/terminal to the repository directory
* run 'gradlew build'
* The built jar file will be in build/libs/
